**Background**
This is my current passion project I have been working on sense the summer of 2026. This is being programmed in Godot using GDscript and the art is being drawn in Aseprite.

**Overview of Repository**
The dream for this project is to be a multiplayer, roguelike, dungeon crawler. The physical combat is similar to that of darkest dungeon, however with an energy system reminiscent of slay the spire but instead of having turn based combat, the entire game is in real time. The environment is and game is based off the table top roll play game Heart: The city beneath.
